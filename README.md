# GenOSWork

Official multi-page website for the **GenOS Agent Runtime**. Built with Next.js App Router, React and TypeScript. The pages are server-rendered; the Morphogenesis Lab adds a small, client-side illustration that does not connect to a live GenOS runtime or execute visitor prompts.

## Develop

Requirements: Node.js 20.19+ and npm.

```sh
npm install
npm run dev
```

Open `http://localhost:3000`.

## Pages

- `/` — public overview
- `/runtime` — runtime lifecycle and boundaries
- `/daemons` — resident daemon archetype, organelles, phenotypes, and limits
- `/topologies` — topology index
- `/topologies/[slug]` — individual profile for each of the eight topologies
- `/lab` — clearly labeled local illustration
- `/evidence` — implementation status and source ledger
- `/developers` — repository entry points and quick start

`/robots.txt` and `/sitemap.xml` are generated by Next.js. The sitemap includes each topology detail page. Update the canonical site URL in `app/layout.tsx` and `app/sitemap.ts` if production hosting changes.

## Source of truth

GenOS runtime and evidence: [github.com/PISSARAW/GenOS](https://github.com/PISSARAW/GenOS)

Public capability statements should stay aligned with the [topology and capability contract](https://github.com/PISSARAW/GenOS/blob/main/docs/02-orchestration/topologies-et-capacites.md) and [morphogenesis plugin limits](https://github.com/PISSARAW/GenOS/blob/main/docs/03-reference/plugins-topologies-morphogenese.md). A capability contract does not mean every declared capability is automatically active.
