# GenOSWork

Official multi-page website for the **GenOS Agent Runtime**. Built with Next.js App Router, React and TypeScript. The pages are server-rendered; the Morphogenesis Lab adds a small, client-side illustration that does not connect to a live GenOS runtime or execute visitor prompts.

## Develop

Requirements: Node.js 20.19+ and npm.

```sh
npm install
npm run dev
```

Open `http://localhost:3000`.

## Pages

- `/` — public overview
- `/runtime` — runtime lifecycle and boundaries
- `/daemons` — resident daemon archetype, organelles, phenotypes, and limits
- `/topologies` — topology index
- `/topologies/[slug]` — individual profile for each of the eight topologies
- `/en/organizations` and `/fr/organizations` — all 19 dynamic organizations, with executable local algorithms, computed visualizations, editable inputs, boundary scenarios, and JSON exports
- `/concepts` — searchable Concept Atlas grouped by 11 system families
- `/concepts/[slug]` — concept definition, source, status axes, limits, and related concepts
- `/systems` — interactive System Map and overview of Concept Atlas families
- `/systems/organism` — biological organism map with explicit analogy limits
- `/lab` — clearly labeled local illustration
- `/lab/models` — eight topology and seven concept browser simulations
- `/evidence` — implementation status and source ledger
- `/ecosystem` and `/fr/ecosystem` — 24 external repositories with GitHub links and observed GenOS integration status
- `/capabilities` and `/capabilities/[slug]` — five cross-cutting capabilities, each with its mechanism, implementation limits, validation question and pinned GenOS sources (also available in French under `/fr/capabilities`)
- `/developers` — repository entry points and quick start

`/robots.txt` and `/sitemap.xml` are generated by Next.js. The sitemap includes the system index and every registered concept and topology detail page. The concept registry and its family taxonomy live in `components/concept-catalog.ts`; the detail-page status vocabulary lives in `components/reality-bar.tsx`. Update the canonical site URL in `app/layout.tsx` and `app/sitemap.ts` if production hosting changes.

## Dynamic organization laboratory

The laboratory ports the 19 deterministic guidance algorithms from the pinned GenOS sources. These calculations run in the browser. Runtime execution, recovery, isolated workers, and durable memory remain subject to the source implementation's documented maturity.

Choose an organization, adjust its parameters or validated JSON input, then run a step. Inspect the computed visualization, exact output, preferred continuations, and role authority. Exports include the source commit and inputs so a calculation can be reproduced. Nominal, boundary, and empty scenarios are available for every organization.

Algorithm tests: `npm test -- --run src/site-integrity/organization-algorithms.test.ts`. When the adjacent GenOS checkout is available, these tests also compare outputs and selectors with the pinned source. For a running preview, execute `node scripts/audit-organizations.cjs` with `PLAYWRIGHT_MODULE` pointing to an installed Playwright module and optionally `ORGANIZATIONS_URL` (default `http://localhost:3001`). The browser audit checks both languages and four viewport widths, and saves its results in `artifacts/organizations/`.
